# Terminal Ink provenance

Terminal Ink is an original implementation created for the `slidev-templates` hosted collection.

The ecosystem survey reviewed public developer-presentation projects such as `LittleSound/talks-template`, `godkun/ppt-template`, `3mdeb/slidev-template`, and other Slidev starters to understand common authoring needs. No code, presentation content, visual assets, logos, or brand identity from those projects is bundled here.

The terminal visual language is implemented with original CSS and generic sample incident data written for this repository. Replace every sample identifier, event, metric, and decision before using the starter for a real incident review.
