# Paper Lab provenance

Paper Lab is an original clean-room implementation created for the `slidev-templates` hosted-template collection.

The initial ecosystem survey included the MIT-licensed project [`luckenco/slidev-academic-GitHub`](https://github.com/luckenco/slidev-academic-GitHub). That project helped identify the need for a reusable academic presentation workflow. Paper Lab does not copy its code, slide content, institutional identity, or assets.

The template uses only CSS, HTML, Markdown, and example text authored for this repository. Replace all sample claims and values before using the starter for a real research presentation.
