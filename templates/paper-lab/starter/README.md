# Paper Lab starter

This directory is the self-contained, directly extractable starter for
[Paper Lab](https://github.com/iridite/slidev-templates/tree/main/templates/paper-lab).

```bash
npm install
npm run dev
```

Use `npm run build` for a static build and `npm run export` for PDF export.
The first export may install or download a Chromium runtime through
Playwright.

Edit `slides.md` directly. The example content is intentionally realistic
enough to demonstrate the information architecture, but every metric, name,
source, and decision is placeholder content and must be replaced.

## Runtime

- Node.js `>=20.12.0`
- `@slidev/cli` `^52.19.1`
- `@slidev/theme-default` `0.25.0`
- Vue `^3.5.33`
