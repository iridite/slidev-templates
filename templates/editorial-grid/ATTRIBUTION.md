# Editorial Grid provenance

Editorial Grid is an original implementation created for the `slidev-templates` hosted collection.

Its composition uses general editorial-design ideas such as asymmetric grids, strong typographic hierarchy, restrained palettes, folio numbering, and alternating statement/evidence pages. These are design principles rather than copied source material.

No code, slide content, commercial template, proprietary typeface, image, logo, or brand identity from another project is bundled. The starter uses system fonts and original CSS and sample copy written for this repository.
